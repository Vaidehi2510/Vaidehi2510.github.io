# vaidehi2510.github.io

My product design portfolio. It's one static page (`index.html`), with no build step.

## GitHub Pages

Site: https://vaidehi2510.github.io

Repository: https://github.com/Vaidehi2510/Vaidehi2510.github.io

GitHub Pages publishes from the root of the `main` branch. The `.nojekyll` file tells GitHub to serve the static files directly.

To publish an update, edit `index.html`, then commit and push the changes to `main`. GitHub Pages redeploys automatically.

The local `resume.pdf` is excluded from Git and is not published.

## Before sending the link

- Replace or add to the wireframes with real screenshots. Put them in an `images/` folder and add `<img src="images/name.png" alt="...">` inside each `<figure>`.
- Read every case study aloud and rewrite anything that doesn't sound like me.
- Check the site on a phone and in dark mode.
